# Service / Услугата

## Purpose / Предназначение

Notes API е учебна REST услуга за създаване, преглеждане и съхраняване на бележки, разработена с Python и FastAPI. Тя е предназначена за упражненията по DevOps и демонстрира проверки за работоспособност, конфигурация чрез променливи на средата и работа с хранилище за данни. По подразбиране бележките се пазят в паметта на приложението; при зададен `DATABASE_URL` се използва PostgreSQL.

## Endpoints / Адреси

При локално стартиране основният адрес е `http://127.0.0.1:8000`.

| Method | Path | What it does / Какво прави |
|---|---|---|
| GET | `/health` | Проверява дали приложението отговаря; връща `{"status": "ok"}`. |
| GET | `/ready` | Проверява дали хранилището за бележки е достъпно; връща `{"status": "ready"}` или HTTP 503 с `{"status": "storage unavailable"}`. |
| GET | `/version` | Връща версията от `APP_VERSION`; по подразбиране `{"version": "0.1.0"}`. |
| GET | `/model` | Показва заредения ML модел чрез полето `model`; без `MODEL_PATH` стойността е `null`. |
| GET | `/notes` | Връща списък с всички бележки (празен списък, ако няма бележки). |
| POST | `/notes` | Създава нова бележка и връща HTTP 201 със създадения обект; изисква `title` (1–100 символа), а `body` е незадължително. |
| GET | `/notes/{note_id}` | Връща бележка по числов идентификатор; ако не съществува, връща HTTP 404. |

За `POST /notes` се изпраща JSON, например `{"title": "Първа бележка", "body": "Здравей"}`. Върнатата бележка съдържа `id`, `title`, `body` и `category` (по подразбиране `null`; може да бъде зададена от ML модела).

FastAPI предоставя и автоматична API документация на `/docs` (Swagger UI), `/redoc` (ReDoc) и OpenAPI описание на `/openapi.json`.

## Dependencies / Зависимости

- **Python 3.12** и пакетите от `requirements.txt`: **FastAPI** (API), **Uvicorn** (ASGI сървър) и **psycopg** (връзка с PostgreSQL).
- **По подразбиране не се изисква външна база данни**: бележките се съхраняват в паметта и се губят след рестарт.
- **PostgreSQL е незадължителен**: при зададен `DATABASE_URL` приложението използва PostgreSQL за постоянно съхранение. Тогава базата трябва да е достъпна, за да работят операциите с бележки и проверката `/ready` да върне успешен резултат.
- **ML моделът е незадължителен**: `MODEL_PATH` посочва файл на обучен модел; за зареждането му са необходими `joblib` и `scikit-learn`. Без модел новите бележки нямат категория.
- **`APP_VERSION` е незадължителна** променлива за стойността, връщана от `/version` (по подразбиране `0.1.0`).
