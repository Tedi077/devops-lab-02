# Glossary / Речник

> Keep the table in alphabetical order. One term per row. / Пазете таблицата по азбучен ред. Един термин на ред.

| Term / Термин | Meaning / Значение |
|---|---|
| Artifact | Резултат от процес на изграждане или тестване (например пакет или отчет), който може да бъде съхранен или публикуван. |
| Branch | Независима линия на разработка в Git, позволяваща промени без директно засягане на основния клон. |
| CI | Continuous integration: every change is built and tested automatically. / Всяка промяна се изгражда и тества автоматично. |
| Commit | Запазена моментна снимка на промени в Git с уникален идентификатор и съобщение. |
| Container | Изолирана среда, която пакетира приложение заедно с необходимите му зависимости. |
| Deployment | Putting a version of the service where users can reach it. / Поставяне на версия на услугата там, където потребителите я достигат. |
| Health check | An endpoint that says whether the service is alive. / Адрес, който казва дали услугата е жива. |
| Issue | A task, bug or idea tracked on GitHub. / Задача, бъг или идея, проследявани в GitHub. |
| Merge | Обединяване на промените от един Git клон в друг. |
| Pipeline | Последователност от автоматизирани стъпки за изграждане, тестване и доставка на промени. |
| Pull request | A proposal to merge one branch into another, with review. / Предложение един клон да се слее в друг, с ревю. |
| Release | Публикувана версия на проект, обикновено обозначена с Git tag и бележки към изданието. |
| Rollback | Връщане към предходна работеща версия след проблем с нова версия. |
| Runner | Машина или процес, който изпълнява заданията на автоматизирана CI/CD система. |
| Tag | Именуван указател към конкретен Git commit, често използван за версия или издание. |
| Version | A named state of the service, e.g. 0.2.0. / Именувано състояние на услугата, напр. 0.2.0. |
